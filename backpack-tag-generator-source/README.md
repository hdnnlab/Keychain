# Backpack Tag Generator

Parametric name-tag tool: type text, get a laser-ready SVG, a printable STL, or a
two-material 3MF.

## Run the source

    npm install
    npm run build          # writes app.css + app.js next to index.html

Then serve the folder (`npx serve .`) and open `index.html`.

## Layout

| File | What it does |
| --- | --- |
| `src/core.js` | All geometry. Flattens opentype outlines, runs the Clipper union/offset/boolean chain, builds the THREE meshes, and writes SVG / STL / 3MF. No DOM access. |
| `src/app.js` | Controls, viewport, unit conversion, export wiring. |
| `src/fonts.js` | Nine OFL fonts, Latin-subset and base64-inlined so the tool works offline. |
| `index.html` | Markup only; every class is generated by the Tailwind build. |

## Current UI configuration

Defaults: Pacifico, weld gap 2%, outline 17%, tag width 50mm, base depth 4mm,
text raise 2mm, hanger top-left with an 8mm ring and 4mm hole.

Three things are deliberately switched off rather than deleted:

- **Base depth / text raise** — inputs still exist in `index.html` but their
  wrapper carries `hidden`. Delete that one class to expose them again.
- **Symbols** — the picker markup and its wiring are gone, but `core.js` still
  has the full symbol library and `buildTag` still honours `symbol.position`.
  `app.js` passes `position: "none"`. Restoring means re-adding controls only.
- **Tag width** is clamped to 50–70mm in both the input attributes and in the
  `f-width` handler, so a tampered DOM can't push it out of range.

## Responsive layout

On phones the preview is `order-1` with a fixed `h-[52vh]`, and the control
column is `order-2 flex-1` with its own scroll. That ordering matters: with the
sidebar first in a column flex container it grows to its content height and
squeezes the canvas to zero, which is why the 3D view was invisible on mobile.
At `lg` the order flips back to sidebar-left and the preview takes `flex-1`.

## Pipeline

    text ──opentype──▶ glyph outlines ──flatten──▶ polygons
                                                     │
                                              union (non-zero)
                                                     │
                                    optional weld (close small gaps)
                                                     ▼
                              offset +outline ──▶ base plate contour
                                                     │
                                     hanger ring union ──▶ bridge islands
                                                     ▼
                                        subtract inner hole
                                                     │
                          ┌──────────────────────────┼──────────────────────┐
                          ▼                          ▼                      ▼
                     SVG (2 layers)          extrude → STL          extrude → 3MF

Bridging runs *after* the ring is welded on and *before* the hole is drilled.
Both orderings matter: a corner-mounted ring can land where the plate's rounded
contour doesn't reach, and drilling last stops a bridge being routed through the
keyring hole.
